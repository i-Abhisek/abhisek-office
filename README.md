# 3D Office Portfolio

## Project structure

- `index.html` — page structure and UI
- `css/style.css` — layout, colors, and responsive styling
- `js/app.js` — office scene, employee models, animations, and interactions
- `js/three.min.js` — bundled Three.js library used by this project

## Run locally

Open this folder in VS Code, then open `index.html` with the Live Server extension. Keep the folder structure intact so the CSS and JavaScript paths resolve.

To customize the portfolio, start in `js/app.js` under `CONFIG`.
